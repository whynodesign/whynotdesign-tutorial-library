# Fonts

- **display**: Instrument Serif
- **text**: Noto Serif TC

Both are Google Fonts under open licences (check each family's licence file before commercial redistribution; outlining into the logo is permitted for OFL/Apache families).

Embed:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Instrument+Serif:wght@400;700&family=Noto+Serif+TC:wght@400;700&display=swap" rel="stylesheet">
```

Font files are not shipped here; self-host from Google Fonts if you need offline use.
