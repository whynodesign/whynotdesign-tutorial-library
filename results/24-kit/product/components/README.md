# Components (HTML)

Plain HTML + `brand/agent/visual/fonts.css` + `tokens.css` + `components.css` + `stave.js`. No build step.
Open in a browser, or screenshot with `tools/render.sh` (all: `tools/render_all.sh`). Query parameters pick data.
React ports would wrap the same functions; not built (Sonata ships .tsx — see RESULT.md).

`stave.js` API (`window.TR`): `lines()`, `levelBar()`, `ember()`, `mark({width, level, reversed, small})`,
`score(data, opts)`, `lineY(n, top, gap)`, `tok(name)`, `num(name)`. Data: `example-batches.js` (**fictional**).
`motion.js` is generated by `tools/build_tokens.py`.
All screenshots are concept renders, not final art.
