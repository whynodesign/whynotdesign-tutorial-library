# Effects

Almost none, on purpose (`visual-system.json` → `effects`): **no shadows, no gradients, no blur, no glow, radius 0.**

The one texture: `assets/textures/rice-paper-grain.png` (procedurally generated noise + fibres, *not* AI), tiled at
512 px, multiply, `--grain-opacity`. Optional on screen, never in print (the stock is the texture).

Print finishes (deboss, varnish) are in `packaging.md`, not here.

## When the rules don't cover it
Don't add the effect.
