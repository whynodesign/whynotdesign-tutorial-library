# style_guide.md — from reference: our own past work (assets/poster_1080x1440_level3.png, assets/social_1080_level5.png)
Taken: grammar only (article block 6: "take the grammar, never the subjects").
- Palette (hex, sampled from the boards): ground #EFE8DA, ink #1E1A17, amber #A8642A, ember #D8432B (one dot, never text). 青瓷灰 #A9B3A1 only for secondary rules.
- Type: display 焙曲 Noto Serif TC 900, very large (≈ 0.2 H). Latin wordmark Lexend Exa 500, tracked +0.3 em. Small labels DM Mono uppercase.
- Layout: split column; right column holds stave above, wordmark below; generous paper margin (≈ 0.08 W).
- Shot lengths: 1.5–2 s per beat group; cuts only on downbeats (120 BPM: every 2 s).
- Transitions: object-driven (the line becomes the stave, the label becomes the bar). No dissolves.
- Camera: almost still; one slow push per shot (≤ 3 %).
- Grain: paper grain on the ground (seeded noise, static per pixel so it doesn't boil).
- Banned defaults: CLAUDE.md "Look" list.
