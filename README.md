# whynotdesign 教程库 · 高清图库

在线浏览：https://whynodesign.github.io/whynotdesign-tutorial-library/

- `img/<id>.<ext>`：117 张条目配图（原尺寸），对应页面锚点 `#e<id>`
- `tests/`：实测成片（remotion / canvas / twoclipping / notdwd 的 mp4）、关键帧和联系表，锚点 `#test-<名称>`
- `results/<id>/`：28 条「值得试」教程的实测结果（测试品牌 焙曲 / TONEROAST），每条有 `RESULT.md`、截图或关键帧和产出文件；页面锚点 `#r<id>`，总览在 `#results`。全部是概念草稿，刀模只到原型级，logo 未做商标检索。53、108 的视频为去掉音轨的静音版；85（PolyForm 非商业）和 108（AGPL）只放我们生成的产出，不含其源码。
